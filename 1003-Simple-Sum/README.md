# 1003 - Simple Sum

## Description

Read two integer values (A and B). Calculate the sum between them and assign it to the variable **SOMA**. Write the value of this variable.

## Specifications

- **Time Limit:** 1 second

## Input

The input file contains 2 integer numbers.

## Output

Print the message "SOMA" in all capital letters, with a blank space before and after the equal signal, followed by the sum value.

**Note:** Always print a newline after the result to avoid "Presentation Error".

## Samples

| Input     | Output     |
| :-------- | :--------- |
| 30<br>10  | SOMA = 40  |
| -30<br>10 | SOMA = -20 |
| 0<br>0    | SOMA = 0   |
