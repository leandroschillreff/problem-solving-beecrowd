# 1000 - Hello World!

## Description

Welcome to beecrowd! Your first program in any programming language is usually "Hello World!". In this first problem, all you have to do is print this message on the screen.

## Specifications

- **Time Limit:** 1 second

## Input

This problem has no input.

## Output

You must print the message **Hello World!** followed by a newline.

## Sample

**Input:**
(none)

**Output:**

```text
Hello World!
```
