# 1001 - Extremely Basic

## Description

Read 2 variables, named A and B, and make the sum of these two variables, assigning its result to the variable X. Print X as shown below.

## Specifications

- **Time Limit:** 1 second

## Input

The input file contains 2 integer numbers.

## Output

Print the letter **X** (uppercase) with a blank space before and after the equal signal followed by the value of X.

**Note:** Always print a newline after the result, otherwise you will receive a "Presentation Error".

## Samples

| Input    | Output |
| :------- | :----- |
| 10<br>9  | X = 19 |
| -10<br>4 | X = -6 |
| 15<br>-7 | X = 8  |
