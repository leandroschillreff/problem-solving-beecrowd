# 1004 - Simple Product

## Description

Read two integer values. Calculate the product between them and store the result in a variable named **PROD**.

## Specifications

- **Time Limit:** 1 second

## Input

The input file contains 2 integer numbers.

## Output

Print the message "PROD" with a blank space before and after the equal signal, followed by the product value.

**Note:** Always print a newline after the result to avoid "Presentation Error".

## Samples

| Input     | Output      |
| :-------- | :---------- |
| 3<br>9    | PROD = 27   |
| -30<br>10 | PROD = -300 |
| 0<br>9    | PROD = 0    |
